# WinPulse-Monitor
Lightweight Windows 10/11 system resource monitor and user-space process manager built with Python and Tkinter.
*(В строчке `git clone` просто замени `YOUR_USERNAME` на свой никнейм на GitHub и нажми **`Commit changes...`**).*

---

### Полезные слова из твоего проекта (в копилку английского):
* **`Lightweight`** — легковесный (не нагружает систему).
* **`Real-Time Telemetry`** — телеметрия (отслеживание показателей) в реальном времени.
* **`Utilization` / `Consumption`** — загрузка / потребление (ресурсов ПК, как на твоих скриншотах Task Manager[cite: 2, 3]).
* **`Terminate a process`** — принудительно завершить процесс.
* **`Dependencies`** — зависимости (внешние библиотеки, которые нужны для работы кода).
